# 🗺️ Hermes Atlas – Die Community-Karte des Hermes-Ökosystems

**Hermes Atlas** ist eine von der Community betriebene, interaktive Karte des gesamten Hermes Agent-Ökosystems. Es katalogisiert 100+ qualitätsgeprüfte, sicherheits-reviewed Tools, Skills, Integrationen und Repos – mit Live-Sternezahlen, Suche und KI-gestütztem Chatbot.

> **Live:** [hermesatlas.com](https://hermesatlas.com/)  
> **GitHub:** [KSimback/hermes-ecosystem](https://github.com/ksimback/hermes-ecosystem)

---

## 🎯 Was Hermes Atlas bietet

| Feature | Beschreibung |
|---------|-------------|
| **🌐 Ecosystem Map** | 100+ kuratierte Einträge in Kategorien wie Core, Skills, Memory, GUIs, Deployment |
| **⭐ Live Star Counts** | Aktuelle GitHub-Sterne mit Sparklines und Trending-Daten |
| **🔍 Volltextsuche** | Schnelles Finden von Tools, Skills und Repos |
| **🤖 RAG-Chatbot** | Stellt Fragen zum Ökosystem mit Quellenangaben (z.B. "best memory provider?", "how to deploy on Docker?") |
| **📊 State of Hermes Report** | Wachstumsmetriken, Architekturnotizen, Community-Stimmung, Ausblick |
| **📰 Newsletter** | Kostenlos, 1–2×/Monat |

## 📊 State of Hermes Report

Der **State of Hermes Report** wird regelmäßig auf Hermes Atlas veröffentlicht und enthält:

- **Wachstumsmetriken** – Repo-Sterne, Contributor-Zahlen, Fork-Raten
- **Architekturnotizen** – Wie das Ökosystem zusammenhängt
- **Community-Stimmung** – Analyse von Diskussionen und Feedback
- **Ausblick** – Trends und kommende Entwicklungen

## 🔗 Integration in dein Hermes-Setup

### Direkt besuchen
Einfach [hermesatlas.com](https://hermesatlas.com/) öffnen – kein Account nötig.

### Newsletter abonnieren
Auf der Seite kannst du den kostenlosen Newsletter abonnieren (1–2×/Monat).

### Eigenes Projekt eintragen
Über ein GitHub-Issue auf [KSimback/hermes-ecosystem](https://github.com/ksimback/hermes-ecosystem) kannst du Projekte zur Aufnahme vorschlagen.
